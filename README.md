# 游戏档案馆 · Game Archive

**31 个浏览器 3D 游戏的中文合集**，按 7 个类别整理，开箱即跑，无需安装编译工具。

所有游戏都在浏览器里直接运行（WebGL / Three.js / Canvas），支持键盘鼠标，部分支持手柄。

## 本地运行

克隆后在本机起一个静态服务器即可（必须用 HTTP，不能用 `file://` 直接双击，否则 ES 模块和跨域会失败）：

```bash
git clone https://github.com/zongyu888/gamecenter.git
cd gamecenter
node server.js        # 然后打开 http://localhost:8080
```

Windows 用户也可以直接双击 `启动游戏中心.bat`。

> 需要 Node.js 14+。没有 Node 也可以用 `python -m http.server 8080` 或 `npx serve`。

## 项目结构

```
gamecenter/
├── index.html            # 门户主页（卡片 / 分类 / 搜索 / 全屏播放）
├── data.js               # 全部游戏数据（名称、分类、简介、操作、路径）
├── sw.js                 # Service Worker：本地缓存，缓存过的游戏断网可玩
├── server.js             # 零依赖本地静态服务器
├── 启动游戏中心.bat       # Windows 一键启动
├── _headers              # Cloudflare Pages 缓存头配置
├── _redirects            # Cloudflare Pages 路由（大文件走 R2）
├── covers/               # 31 张封面（WebP）
└── games/
    ├── action/           # 动作射击
    ├── racing/           # 竞速
    ├── survival/         # 生存
    ├── puzzle/           # 解谜
    ├── multiplayer/      # 多人对战
    ├── art/              # 艺术漫游
    ├── showcase/         # 场景展示
    └── _fonts/           # 共享自托管字体（避免外链阻塞）
```

每个游戏目录都是自包含的：`index.html` + `assets/`，直接部署这一层就能单独访问。
单文件游戏是一个 HTML 里内联了全部代码和资源，拷走就能玩。

## 技术说明

- **零后端**：纯静态站点，任何静态托管（GitHub Pages / Cloudflare Pages / Nginx）都能跑。
- **懒加载**：封面用 `IntersectionObserver` 延迟载入；游戏 iframe **点了才创建**，关闭即销毁释放 WebGL 上下文 —— 不玩的不占带宽和显存。
- **本地缓存**（`sw.js`）：首次只预缓存门户外壳 + 31 张封面（<1MB）；游戏资源**只缓存玩家实际打开过的**，单个超 40MB 的文件不落地，防止撑爆磁盘。缓存过的游戏断网也能玩。
- **边缘缓存**（`_headers`）：带 hash 的构建产物一年 immutable，封面浏览器 7 天 / 边缘 30 天，入口文件短缓存保证更新生效。
- **字体自托管**：所有外链 Google Fonts 已下载到 `games/_fonts/` 并内联 `@font-face`，避免国内访问被墙导致页面卡在渲染阻塞。
- **大文件分流**：Cloudflare Pages 单文件上限 25MB，哈罗农场的 36MB 模型通过 `_redirects` 301 到对象存储（R2）。
- **预热**：点开游戏详情弹窗时，Service Worker 会提前拉取该游戏入口 HTML 与主脚本（含 `modulepreload`），点「开始游戏」时秒开。
