## 简介

### 科纳音乐厅 · 古钢琴声学 · Koerner Hall

交互式 3D 声学模拟。以 CAD 重建的 1780 年 Stein-Schule 南德古钢琴、五段同步的公有领域古钢琴录音，以及全场 1135 个座位各不相同的混响效果。

- **操作**：点击座位切换听音位置 · 佩戴耳机效果最佳
- **标签**：音乐 · 声学 · 3D展示
- **入口**：[`games/showcase/koerner-hall/`](../../games/showcase/koerner-hall/)

### 像素与系统 · 活动主页 · Event Landing Page

为期三天的虚构会议网站，主题围绕像素、字体、界面与系统。一个排版与视觉设计的展示项目。

- **操作**：滚动浏览 · 点击交互
- **标签**：设计 · 展示 · 网页
